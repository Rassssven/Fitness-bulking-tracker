# Fitness Buling Tracker

Full-stack bulking & fitness tracker — workouts, nutrition and body weight progress.
🔧 Work In progress

# Overview

This app helps users track their fitness journey with features designated to support correct training and cleaner eating habits.
Users can log daily workouts and meals, and monitor body weight progress over time. Users can also create plans for achieving their goals.

# Tech stack

  - Backend: SpringBoot
  - Frontend: Angular, Kendo UI
  - Logging: Log4j2
  - Database: Postgresql
